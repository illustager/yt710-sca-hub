# 倚天 710 侧信道原语移植与复现

实验室内部参考仓库。各成员在**独立仓库**中维护自己的原语实现与测试代码；本仓库只负责三件事：

1. **原语索引**：谁、在哪个仓库、复现了哪个原语、验证到哪个版本；
2. **平台约定**：倚天 710 的测量环境、频率策略、perf 权限、缓存几何等公共知识；
3. **已验证快照**：将有成果的测试代码提交为 submodule。

本仓库不承担代码集成职责，也不要求各仓库的代码风格、构建方式统一。

### 说明

状态：

- WIP：代码可运行，但工作尚未完成
- 可用：工作完成，确认原语可用或基本可用（误码率低于 10%）
- 受限：工作完成，确认原语可用但有显著限制，例如误码率高、需要特权级等
- 不可用：工作完成，确认原语不可用
